# TestDrive game media

Pictures and clips of the TestDrive game (its characters, weapons and scenery), shown by the game's
Art page: https://torahworldwide.github.io/testdrive-pages/art.html

GitHub Pages serves every file here at https://torahworldwide.github.io/testdrive-media/<path>, and
`art/index.json` lists them. Each publish replaces everything with one new commit, so this repo keeps
no history. Built and published by `GamePages/publish_media.py` in the game's repo.
